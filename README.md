# Лабораторная работа 5 — DES CBC

Самостоятельный проект C# для шифрования и расшифрования файлов в режиме DES CBC. Содержит только исходники этой работы и реализацию DES, без ссылок на общий проект. Открой `Lab5.sln` или собери `Lab5.csproj`.

```powershell
dotnet run -- encrypt вход.bin шифр.bin
dotnet run -- decrypt шифр.bin результат.bin
```

Можно передать ключ и IV в HEX как дополнительные аргументы. По умолчанию используются учебный ключ `133457799BBCDFF1` и IV из датчика лабораторной 3. CBC обрабатывает только целое число 8-байтовых блоков; дополнение не применяется.
